# Image Editor

This is a browser-based Image Editor built using HTML, CSS, and JavaScript. The project allows users to upload an image and make various adjustments directly in the browser without using any external software.

Users can modify properties such as brightness, contrast, saturation, blur, opacity, grayscale, and sepia through simple controls. The editor also provides options to rotate and flip images while displaying the changes instantly in the preview section.

One of the main features of this project is the ability to download the edited image with all applied modifications. This was achieved using the HTML Canvas API, which redraws the image along with the selected filters and transformations before generating the final downloadable file.

While building this project, I gained practical experience with DOM manipulation, event handling, image processing, CSS filters, file handling, and working with the Canvas API. The project helped me better understand how modern web applications can perform image editing tasks directly in the browser.
